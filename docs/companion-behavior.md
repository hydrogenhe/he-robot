# 连续陪伴行为

五项行为复用现有主人私聊、主动消息、材料阅读和成长流程，不增加独立的定时发送额度。

- **事件跟进**：同一轮模型理解可提出未来事件、结果反馈或停止追问。程序核对逐字引文属于当前主人实际消息，限定未来31天内时间，最多保留20项。到期跟进占用既有随机聊天槽；发起后即标记已问，失败或未回复不反复催问；超过7天的过期跟进不补发。绑定、记忆代际和机器人隔离，关闭私聊记忆不新存事件。
- **有缘由的分享**：随机聊天优先采用待跟进事件，否则选择最近72小时真实材料经历，并查询当前主人获准的相关记忆。引用来源去重，不编造共同经历；保留没有相关素材时的普通问候。
- **持续探索**：完整阅读材料后保存一个公开兴趣主题及下一步问题。角色兴趣模式优先加入该检索词，持续3天；新材料逐步更新问题，过期不自动无限延长，同主题7天内不反复重开。自定义浏览模式及排除词仍优先，沿用原视频日上限。
- **状态影响表达**：已有情绪随时间减弱。明显情绪需要连续两次相反方向的真实信号才切换，避免一条消息直接翻转；状态影响表达指引及表情候选概率，严肃话题继续优先。模拟情绪不改变回复权限，不索取陪伴。
- **交流节奏**：主人明确忙闲时，模型提出0–1440分钟的主动闲聊暂停（未给时长时120分钟），不影响来信回复或日记/视频通知。现有消息批次内，8秒内最多3条、合计500字的连续补充合并理解后回复；未发送尾段遇到新来信仍沿用既有中断机制。

主动跟进和分享仍遵守北京时间00–09免打扰、发送预检、冷却、未知结果不重发和现有每天3–5次随机聊天额度。模型用量沿用本轮计量，状态提取不额外请求模型。

查询和表达提示词仍遵守原总输入预算；必要时按现有优先级裁剪上下文，为固定指令预留空间。个人状态只写入本机数据目录，不包含在源码与下载包中。
