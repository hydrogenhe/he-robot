# 本地操作

以下命令在本文件所在的 scripts/ 目录执行；每项独立运行。Go 1.25+ 用于源码构建，预编译程序运行不需要 Go 或 Node.js。

编译当前代码（不修改版本号）：

```bash
bash build.sh
```

启动并打开本地页面（优先打开已有实例，前台运行，Ctrl+C停止）：

```bash
../bin/gpt-robot serve --root .. --open
```

验证核心行为（临时数据、模拟平台、回环测试端口；若已安装Node，另运行网页脚本测试）：

```bash
bash test.sh
```

输出本机 Codex stdio MCP 配置（仅显示配置，不覆盖其他 MCP）：

```bash
../bin/gpt-robot config --root ..
```

源码修改后先编译，再停止自己的旧实例并重新启动；启动时发现端口占用不会改写活动账本。

构建三个平台的预编译 ZIP 与校验值（需要 Go、Python 3；只输出到 dist/，不上传）：

```bash
python3 release/package.py v0.2.0
```
