# 栖 · GPT Robot

给 AI 角色一个本地的家：独立人设、记忆、成长、日记和受控的平台互动。

Go 后端、内置网页工作台、嵌入式 SQLite 与 stdio MCP。本地预览版，当前优先支持 macOS 与本机 Codex / DeepSeek Harness；QQ、抖音接入及 Windows 使用尚未完成验收。

## 下载与启动

首次使用需要 Go 1.25+。在 GitHub 点击 **Code → Download ZIP**，解压后在项目目录运行：

```bash
bash scripts/build.sh
bin/gpt-robot serve --root . --open
```

macOS 也可双击 `scripts/start.command`，缺少程序时自动从源码构建。构建后的程序不需要 Go、Node.js 或另装数据库服务。当前提供源码下载，尚无预编译安装包。

打开或收藏 <http://127.0.0.1:3217/>。服务仅监听本机；保持终端运行，按 Ctrl+C 停止。网页“关闭机器人”保留控制台，“退出整个程序”才停止服务。

首次启动自动创建属于你自己的配置和数据库。下载包不包含作者的账号、角色、记忆、日记、聊天记录或凭证。请在网页设置你自己的角色，再配置模型与互动平台。

## 使用

1. 在“角色设定”编辑身份、表达方式和偏好。
2. 在“大模型配置”选择已安装并登录的本机 Harness、型号与思考档位。模型运行时不随本项目捆绑；需要自行安装并取得使用权限，实际模型请求可能产生用量或费用。
3. 在“互动平台 → B站”扫码登录自己的账号。默认发送和自主浏览关闭；需要时再配置允许范围、额度和冷却。
4. 读取评论并准备草稿，在网页核对账号、目标、正文后审核发送。自动回复需单独明确开启；私信只对绑定对象开放。
5. 在工作台查看历史、记忆、角色成长、日记及真实模型用量。未知用量不计作零。

角色只应依据真实读取内容和经历回答。当前视频理解脚本属于实验，尚未接入日常浏览；不能将标题、简介或评论读取视为观看完整视频。平台使用非官方 Web 接口，可能发生变化或限制。

## 数据与隐私

所有运行资料保存在你指定的 `--root` 目录：

| 目录 | 内容 |
| --- | --- |
| `data/` | 角色、独立 SQLite 数据库、记忆、日记和活动历史 |
| `config/` | 本机模型、平台、权限与运行配置 |
| `.private/` | 登录凭证、网页会话与私有运行日志 |

以上目录均被 Git 忽略。备份请自行妥善保管；不要上传或分享这些目录。文件权限保护不等于加密。公开、私聊及不同账号的上下文按范围隔离；朋友关系不扩大隐私访问或发送权限。

发送前仍检查账号、授权、额度和防重复。超时或无回执视为结果未知，不自动重发；账号内可查不代表公开可见。本项目无法隔离拥有同用户文件及命令权限的整个宿主。

## Codex MCP

保持工作台运行，执行以下命令生成本机配置片段：

```bash
bin/gpt-robot config --root .
```

把输出按宿主文档加入 MCP 配置。提供角色上下文、记忆检索/记录、B站状态与评论读取、评论/动态草稿共 7 个工具；不开放直接发送或修改权限工具。新聊天按需读取本地角色和相关记忆，不依赖开发聊天历史。

## 开发与验证

```bash
bash scripts/test.sh
```

测试使用临时资料、模拟平台与回环测试端口，不向真实平台发送内容。有 Node.js 时会额外运行网页脚本测试，Node.js 不是运行依赖。操作命令见 [操作入口](scripts/操作入口.md)，接口定义见 [OpenAPI](docs/openapi.yaml)。

通用业务在 `core/`，数据存储在 `storage/`，模型适配在 `businesshost/` 与 `modelprovider/`，平台适配在 `platforms/`，网页在 `web/`。扩展平台应复用权限、记忆和用量规则，保持账号与隐私隔离。
